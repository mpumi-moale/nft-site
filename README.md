# 💎 Wildly Expensive JPEGs

### Also Known as NFTs™

A satirical NFT landing page for people who have **way too much money and questionable financial decisions.**

> *Why spend R33 on sneakers when you can spend R33,000 on a JPEG of sneakers?*

**Wildly Expensive JPEGs** is a humorous frontend project that parodies the world of NFTs, crypto collectibles, and absurdly expensive digital assets.

## 🖼️ About The Project

This project imagines an online marketplace where completely ordinary—or deliberately ridiculous—digital assets are sold for extraordinary amounts of money.

The site features fictional NFT products including:

* 👟 **Meta-Pigeon Sneaker NFT** — `R33,000`
* 🧑‍🎤 **CryptoPunk** — `R6.6 Million`
* 👜 **Bag #748** — `R1.4 Million`

The goal is to create a fun, visually engaging website while practicing fundamental frontend development concepts.
